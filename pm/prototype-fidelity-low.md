## Fidelity: low (wireframe)

This version is a wireframe. Its job is to settle structure and flow before anyone discusses looks.

- The kit's wireframe theme applies automatically: greyscale, no brand colour, no logo, flat surfaces. Do not try to add colour or polish.
- Spend the effort on layout, navigation, flow between screens, labels and states. Every screen, role and state in the plan is present and reachable.
- Use real labels and short realistic sample data so the flow can be judged, but keep content lean: a few rows per table, one example per pattern.
- Use the kit components plainly. No decorative detail, no imagery beyond `.placeholder` blocks, icons only where they mark an action or a nav item.
- Show every state as its own block (empty, loading, error, permission-limited) with the message and the next step written out.
